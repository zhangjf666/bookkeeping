## 6. 状态管理数据流

### 6.1 Store 结构

```
Pinia Store
├── user (用户状态)
│   ├── id: number
│   ├── username: string
│   ├── nickname: string
│   ├── avatar: string
│   └── roles: string[]
│
├── bill (账单状态)
│   ├── accountBooks: AccountBook[]
│   ├── currentAccountBook: AccountBook | null
│   ├── classifyList: Classify[]
│   ├── classifyTree: Classify[]
│   ├── tagList: Tag[]
│   ├── remarkList: Remark[]
│   ├── list: IncomeExpense[]
│   ├── total: number
│   ├── queryParams: IncomeExpenseQuery
│   └── listLoading: boolean
│
└── app (应用状态)
    ├── device: 'pc' | 'mobile'
    ├── sidebar: boolean
    └── theme: string
```

### 6.2 数据流向规则

1. **单向数据流**：View → Action → State → View
2. **API 调用**：只在 Action 中进行
3. **状态修改**：通过 Action 方法，不直接修改 State
4. **跨组件通信**：通过 Store 共享状态

## 7. 缓存策略

### 7.1 本地存储
| 数据 | 存储位置 | 有效期 |
|------|----------|--------|
| Token | localStorage | 7 天 |
| 用户信息 | Pinia + localStorage | 随 Token |
| 账本列表 | Pinia | 会话期间 |
| 分类/标签 | Pinia | 会话期间 |

### 7.2 页面缓存
使用 `<keep-alive>` 缓存页面组件：
- 首页
- 账单列表
- 报表页
