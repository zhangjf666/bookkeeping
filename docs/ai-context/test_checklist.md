## 真机测试
使用手机浏览器访问开发服务器地址进行测试：
1. 确保手机和电脑在同一局域网
2. 访问 `http://[电脑IP]:8850/`
3. 验证以上所有功能

## Chrome DevTools 模拟测试
1. 打开 Chrome DevTools (F12)
2. 点击设备模拟图标
3. 选择 iPhone 或 Android 设备
4. 刷新页面进行测试
