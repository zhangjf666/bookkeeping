# 统计报表模块 PRD

## 一、功能描述

### 1.1 功能概述

统计报表模块为用户提供多维度的收支数据分析，帮助用户了解自己的财务状况，包括账单统计和分类统计。

### 1.2 功能需求

- **账单统计**: 查看指定时间范围内的收支趋势图表和账单明细
- **分类统计**: 查看支出/收入的分类占比饼图和柱状图

### 1.3 左侧菜单结构

```
- 首页 (/dashboard)
- 收入支出记录 (/bill)
- 统计报表 (/report)
  - 账单统计 (/report/bill)
  - 分类统计 (/report/category)
- 设置
  - 通用设置 (/settings/common)
  - 账本设置 (/settings/account-book)
  - 分类设置 (/settings/classify)
  - 备注设置 (/settings/remark)
  - 标签设置 (/settings/tag)
```

## 二、用户流程

### 2.1 账单统计流程

```
用户进入账单统计页面
        ↓
默认选中用户当前账本
        ↓
默认选择月账单类型，当月时间范围
        ↓
选择查询条件（账本/账单类型/时间/分类）
        ↓
点击查询按钮调用 /sumPeriod 接口
        ↓
渲染收支趋势图表和账单明细表格
```

### 2.2 分类统计流程

```
用户进入分类统计页面
        ↓
默认显示本月数据
        ↓
选择账本和时间范围
        ↓
分别显示支出分类和收入分类的占比
        ↓
点击分类可查看该分类的详细记录
```

## 三、接口定义

### 3.1 获取账单统计数据

**请求**

```
GET /incomeExpense/sumPeriod
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| accountBookId | Long | 否 | 账本ID，不传则查询所有账本 |
| mode | String | 是 | 查询模式：0-月，1-年，2-自定义 |
| queryMode | String | 否 | 查询方式：0-账单，1-报表，默认0 |
| beginDate | String | 是 | 开始日期 (yyyy-MM-dd) |
| endDate | String | 是 | 结束日期 (yyyy-MM-dd) |
| classifyList | Array | 否 | 分类ID列表 |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "expenseTotal": 5000.00,
    "incomeTotal": 8000.00,
    "expenseLimit": 10000.00,
    "expenseSurplus": 5000.00,
    "incomeExpenseSum": {
      "2026-03-12": {
        "income": 0.00,
        "expense": 150.00
      },
      "2026-03-13": {
        "income": 5000.00,
        "expense": 80.00
      }
    },
    "incomeExpenseList": [
      {
        "id": 1,
        "amount": 50.00,
        "type": 0,
        "date": "2026-03-18",
        "remark": "午餐",
        "mainClassifyName": "餐饮",
        "subClassifyName": "午餐"
      }
    ]
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| expenseTotal | BigDecimal | 总支出 |
| incomeTotal | BigDecimal | 总收入 |
| expenseLimit | BigDecimal | 当前支出限额 |
| expenseSurplus | BigDecimal | 当前支出剩余 |
| incomeExpenseSum | Dict | 收入支出统计列表，key为日期(yyyy-MM-dd)，value包含income和expense |
| incomeExpenseList | List | 收支详细列表 |

### 3.2 获取分类统计数据

**请求**

```
GET /incomeExpense
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | String | 是 | 开始日期 |
| endDate | String | 是 | 结束日期 |
| accountBookId | Long | 否 | 账本ID |
| type | String | 是 | 类型：0-支出，1-收入 |

**响应**（需要按分类聚合）

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "classifyId": 1,
      "classifyName": "餐饮",
      "totalAmount": 1500.00,
      "count": 30,
      "percentage": 25.0
    },
    {
      "classifyId": 2,
      "classifyName": "交通",
      "totalAmount": 600.00,
      "count": 20,
      "percentage": 10.0
    }
  ]
}
```

## 四、页面设计

### 4.1 账单统计页面

#### 4.1.1 查询条件模块

```
┌─────────────────────────────────────────────────────────────────┐
│  账本：[日常账本 ▼]                                             │
│  账单类型：[月账单 ▼]  时间：[2026-03 ▼]                        │
│  分类：[请选择 ▼]（下拉多选，显示所有主分类）                     │
│                                                   [查询] [重置]  │
└─────────────────────────────────────────────────────────────────┘
```

**查询条件说明：**

| 条件 | 说明 |
|------|------|
| 账本 | 进入页面时默认填写用户当前选中的账本ID |
| 账单类型 | 下拉选择：月账单、年账单、自定义 |
| 时间选择 | 根据账单类型显示不同的选择器 |
| 分类 | 下拉多选框，显示pid=-1的主分类列表，勾选后放入classifyList |
| 查询按钮 | 点击调用 /sumPeriod 接口 |
| 重置按钮 | 清除所有查询条件，恢复默认值 |

**账单类型与时间选择器对应关系：**

| 账单类型 | 时间选择器类型 | beginDate | endDate |
|---------|--------------|-----------|---------|
| 月账单 | 年月选择器（只显示到年月） | 选择月份第一天 | 选择月份最后一天 |
| 年账单 | 年份选择器（只显示到年） | 选择年份第一天 | 选择年份最后一天 |
| 自定义 | 日期范围选择器 | 选择的开始日期 | 选择的结束日期 |

#### 4.1.2 图表显示区域

```
┌─────────────────────────────────────────────────────────────────┐
│  总收入: ¥8,000        总支出: ¥5,000                           │
│  ┌───────────────────────────────────────────────────────────┐  │
│  │  ████████  ████████                                        │  │
│  │  ██████    ████████                                        │  │
│  │  03-01    03-02    03-03                                   │  │
│  └───────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

**图表说明：**
- 图表类型：柱状图
- 左上角显示总收入(incomeTotal)和总支出(expenseTotal)
- 不需要月/季度/近半年/年的周期切换选项，只显示查询结果
- X轴标签格式：月账单/自定义显示MM-DD，年账单显示YYYY-MM

## 六、图表配置

### 6.1 账单统计图表配置

- 类型：柱状图
- X轴：日期（根据账单类型显示不同格式）
- Y轴：金额
- 左上角显示总收入和总支出
- 不支持周期切换，只显示查询结果数据

### 6.2 分类统计图表配置

- 类型：饼图 + 柱状图
- 饼图：显示各类别占比
- 柱状图：显示各类别金额
- 支持支出/收入切换
