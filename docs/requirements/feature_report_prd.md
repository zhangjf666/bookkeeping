# 统计报表模块 PRD

## 一、功能描述

### 1.1 功能概述

统计报表模块为用户提供多维度的收支数据分析，帮助用户了解自己的财务状况，包括趋势分析、分类统计和对比分析。

### 1.2 功能需求

- **趋势分析**: 查看日/周/月的收支趋势折线图
- **分类统计**: 查看支出/收入的分类占比饼图和柱状图
- **对比分析**: 查看月度或年度收支对比

---

## 二、用户流程

### 2.1 趋势分析流程

```
用户进入趋势分析页面
        ↓
默认显示最近7天收支趋势
        ↓
选择账本（可选）
        ↓
选择时间周期（日/周/月）
        ↓
图表自动刷新
        ↓
鼠标悬停查看具体数据
```

### 2.2 分类统计流程

```
用户进入分类统计页面
        ↓
默认显示本月数据
        ↓
选择账本和时间范围
        ↓
分别显示支出分类和收入分类的占比
        ↓
点击分类可查看该分类的详细记录
```

### 2.3 对比分析流程

```
用户进入对比分析页面
        ↓
默认显示月度对比（最近6个月）
        ↓
选择对比类型（月度/年度）
        ↓
图表展示多个月份/年份的收支对比
        ↓
支持柱状图和折线图切换
```

## 三、接口定义

### 3.1 获取报表数据（趋势/对比分析）

**请求**

```
GET /incomeExpense/sumPeriod
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| periodType | String | 是 | 统计周期：day-日，week-周，month-月 |
| startDate | String | 是 | 开始日期 (yyyy-MM-dd) |
| endDate | String | 是 | 结束日期 (yyyy-MM-dd) |
| accountBookId | Long | 否 | 账本ID |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "date": "2026-03-16",
      "expenseAmount": 150.00,
      "incomeAmount": 0.00
    },
    {
      "date": "2026-03-17",
      "expenseAmount": 80.00,
      "incomeAmount": 5000.00
    }
  ]
}
```

### 3.2 获取分类统计数据

**请求**

```
GET /incomeExpense
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | String | 是 | 开始日期 |
| endDate | String | 是 | 结束日期 |
| accountBookId | Long | 否 | 账本ID |
| type | String | 是 | 类型：0-支出，1-收入 |

**响应**（需要按分类聚合）

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "classifyId": 1,
      "classifyName": "餐饮",
      "totalAmount": 1500.00,
      "count": 30,
      "percentage": 25.0
    },
    {
      "classifyId": 2,
      "classifyName": "交通",
      "totalAmount": 600.00,
      "count": 20,
      "percentage": 10.0
    }
  ]
}
```

## 六、图表配置

### 6.1 趋势分析图表配置

- 类型：折线图
- X轴：日期
- Y轴：金额（双轴，左侧支出，右侧收入）
- 支持日/周/月切换
- 鼠标悬停显示详细数值

### 6.2 分类统计图表配置

- 类型：饼图 + 柱状图
- 饼图：显示各类别占比
- 柱状图：显示各类别金额
- 支持支出/收入切换

### 6.3 对比分析图表配置

- 类型：柱状图 + 折线图
- 柱状图：显示每月收支金额
- 折线图：显示结余趋势
