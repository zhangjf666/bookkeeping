# 标签设置模块 PRD

## 一、功能描述

### 1.1 功能概述

标签设置模块用于管理用户自定义的记账标签，方便对记账记录进行分类和检索。

### 1.2 功能需求

- 查看标签列表
- 按标签名称搜索
- 新增标签
- 编辑标签（名称、颜色、排序）
- 删除标签（单条删除）
- 批量删除标签
- 标签排序

---

## 二、用户流程

```
用户进入标签设置页面
        ↓
查看已有的标签列表
        ↓
(可选) 输入标签名称进行搜索 → 点击"查询"或按回车
        ↓
点击"新增"按钮 → 输入标签名称、选择颜色 → 保存
        ↓
标签数据更新 → 刷新全局标签缓存（供其他页面使用）
        ↓
点击某条标签的"编辑"按钮 → 修改内容 → 保存
        ↓
标签数据更新 → 刷新全局标签缓存
        ↓
点击"删除"按钮 → 确认删除
        ↓
标签数据更新 → 刷新全局标签缓存 → 列表刷新
```

## 三、接口定义

### 3.1 查询用户标签（分页）

**请求**

```
GET /userTag/page
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 否 | 标签名称（模糊搜索） |
| pageNo | Integer | 否 | 页码（默认1） |
| pageSize | Integer | 否 | 每页条数（默认10） |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "totalCount": 2,
    "record": [
      {
        "id": 1,
        "userId": 1,
        "name": "重要",
        "color": "#FF6B6B80",
        "sort": 1,
        "createTime": "2026-03-01 10:00:00",
        "updateTime": "2026-03-01 10:00:00"
      },
      {
        "id": 2,
        "userId": 1,
        "name": "报销",
        "color": "#4ECDC480",
        "sort": 2,
        "createTime": "2026-03-01 10:00:00",
        "updateTime": "2026-03-01 10:00:00"
      }
    ]
  }
}
```

### 3.2 创建用户标签

**请求**

```
POST /userTag
```

**请求体**

```json
{
  "userId": 1,
  "name": "出差",
  "color": "#95E1D380",
  "sort": 3
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 是 | 标签名称 |
| color | String | 否 | 标签颜色（8位十六进制RGBA，如 #FF6B6B80，最后两位表示透明度） |
| sort | Integer | 否 | 排序号 |

### 3.3 更新用户标签

**请求**

```
PUT /userTag
```

**请求体**

```json
{
  "id": 1,
  "userId": 1,
  "name": "重要（修改）",
  "color": "#FF6B6B80",
  "sort": 1
}
```

### 3.4 删除用户标签

**请求**

```
DELETE /userTag
```

**请求体**

```json
[1, 2]
```

└─────────────────────────────────────────────────────────────┘
```

**页面功能说明：**

- **查询条件区域**：
  - 标签名称输入框：支持按标签名称模糊搜索
  - 查询按钮：执行搜索过滤
  - 重置按钮：清空搜索条件并显示全部

- **操作按钮**：
  - 新增标签：打开新增标签弹窗
  - 批量删除：删除选中的标签（需先勾选至少一条记录），按钮右侧显示已选中的数量，如"批量删除 (2)"

- **表格**：
  - 复选框列：支持多选
  - 排序号：显示标签排序
  - 标签名称：显示标签名称和标签样式
  - 颜色：显示颜色值和颜色预览
  - 操作：编辑、删除按钮

### 5.2 新增/编辑弹窗

```
┌─────────────────────────────────────────────────────────────┐
│  新增标签                                         ✕          │
├─────────────────────────────────────────────────────────────┤
│  标签名称:  [________________________________]              │
│            (最多20个字符)                                    │
│                                                              │
│  标签颜色:                                                   │
│  [颜色选择器 - 支持 RGBA 拾色器]                            │
│  - 支持直接输入十六进制颜色值                                │
│  - 支持透明度调整 (0-100%)                                   │
│  - 预设常用颜色快捷选择                                      │
│  - 颜色格式: #RRGGBBAA (如 #FF6B6B80)                       │
│                                                              │
│  预览:  [标签名称]                                          │
│         (实时显示标签颜色效果)                               │
│                                                              │
│  排序:  [___]                                               │
├─────────────────────────────────────────────────────────────┤
│                                             [取消] [保存]   │
└─────────────────────────────────────────────────────────────┘
```

**颜色格式说明：**

- 使用 8 位十六进制颜色格式：#RRGGBBAA
- RR：红色分量 (00-FF)
- GG：绿色分量 (00-FF)
- BB：蓝色分量 (00-FF)
- AA：透明度 (00-FF，00 为完全透明，FF 为完全不透明)
- 示例：#FF6B6B80 = 红色 50% 透明度

**颜色选择器预设（30个常用颜色，3行×10列）：**

```

## 八、数据缓存管理

标签数据用于收支记录等页面的标签选择功能，因此在标签发生新增、修改、删除操作后，需要刷新全局标签缓存。

**缓存刷新时机：**
- 新增标签成功后
- 修改标签成功后
- 删除标签成功后

**实现方式：**
调用 `billStore.loadClassifyAndTag(userId)` 或单独刷新标签列表，确保其他页面使用最新的标签数据。
