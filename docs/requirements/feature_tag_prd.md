# 标签设置模块 PRD

## 一、功能描述

### 1.1 功能概述

标签设置模块用于管理用户自定义的记账标签，方便对记账记录进行分类和检索。

### 1.2 功能需求

- 查看标签列表
- 新增标签
- 编辑标签（名称、颜色）
- 删除标签
- 标签排序

---

## 二、用户流程

```
用户进入标签设置页面
        ↓
查看已有的标签列表
        ↓
点击"新增"按钮 → 输入标签名称、选择颜色 → 保存
        ↓
点击某条标签的"编辑"按钮 → 修改内容 → 保存
        ↓
点击"删除"按钮 → 确认删除
        ↓
列表刷新
```

---

## 三、接口定义

### 3.1 查询用户标签

**请求**

```
GET /userTag
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "tagName": "重要",
      "color": "#FF6B6B",
      "sort": 1,
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    },
    {
      "id": 2,
      "userId": 1,
      "tagName": "报销",
      "color": "#4ECDC4",
      "sort": 2,
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    }
  ]
}
```

### 3.2 创建用户标签

**请求**

```
POST /userTag
```

**请求体**

```json
{
  "userId": 1,
  "tagName": "出差",
  "color": "#95E1D3",
  "sort": 3
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| tagName | String | 是 | 标签名称 |
| color | String | 否 | 标签颜色（RGBA十六进制，如 #FF6B6B80，支持透明度） |
| sort | Integer | 否 | 排序号 |

### 3.3 更新用户标签

**请求**

```
PUT /userTag
```

**请求体**

```json
{
  "id": 1,
  "userId": 1,
  "tagName": "重要（修改）",
  "color": "#FF6B6B",
  "sort": 1
}
```

### 3.4 删除用户标签

**请求**

```
DELETE /userTag
```

**请求体**

```json
[1, 2]
```

## 四、数据结构

### 4.1 用户标签 (UserTag)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键ID |
| userId | Long | 用户ID |
| tagName | String | 标签名称 |
| color | String | 标签颜色（RGBA十六进制，支持透明度，如 #FF6B6B80） |
| sort | Integer | 排序号 |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |
