# 备注设置模块 PRD

## 一、功能描述

### 1.1 功能概述

备注设置模块用于管理用户常用的记账备注，方便在记账时快速选择常用备注，提高记账效率。

### 1.2 功能需求

- 查看常用备注列表
- 新增常用备注
- 编辑常用备注
- 删除常用备注
- 常用备注排序

---

## 二、用户流程

```
用户进入备注设置页面
        ↓
查看已有的常用备注列表
        ↓
点击"新增"按钮 → 输入备注内容 → 保存
        ↓
点击某条备注的"编辑"按钮 → 修改内容 → 保存
        ↓
点击"删除"按钮 → 确认删除
        ↓
列表刷新
```

---

## 三、接口定义

### 3.1 查询用户备注

**请求**

```
GET /userRemark
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "remark": "午餐",
      "sort": 1,
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    },
    {
      "id": 2,
      "userId": 1,
      "remark": "晚餐",
      "sort": 2,
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    }
  ]
}
```

### 3.2 创建用户备注

**请求**

```
POST /userRemark
```

**请求体**

```json
{
  "userId": 1,
  "remark": "早餐",
  "sort": 3
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| remark | String | 是 | 备注内容 |
| sort | Integer | 否 | 排序号 |

### 3.3 更新用户备注

**请求**

```
PUT /userRemark
```

**请求体**

```json
{
  "id": 1,
  "userId": 1,
  "remark": "午餐（修改）",
  "sort": 1
}
```

### 3.4 删除用户备注

**请求**

```
DELETE /userRemark
```

**请求体**

```json
[1, 2]
```
