# 账本设置模块 PRD

## 一、功能描述

### 1.1 功能概述

账本设置模块用于管理用户的记账账本，方便对不同账本进行分类管理和使用。

### 1.2 功能需求

- 查看账本列表
- 按账本名称搜索
- 新增账本
- 编辑账本
- 删除账本（单条删除），默认账本不能删除
- 批量删除账本，默认账本不能删除
- 设置默认账本（只能有一个默认账本，设置新默认时会取消旧的）

---

## 二、用户流程

```
用户进入账本设置页面
        ↓
查看已有的账本列表
        ↓
(可选) 输入账本名称进行搜索 → 点击"查询"或按回车
        ↓
点击"新增"按钮 → 输入账本名称、选择账本图标、选择是否默认 → 保存
        ↓
如果是默认账本设置，则自动取消其他账本的默认状态
        ↓
账本数据更新 → 刷新全局账本缓存（供其他页面使用）
        ↓
点击某条账本的"编辑"按钮 → 修改内容 → 保存
        ↓
如果是默认账本设置，则自动取消其他账本的默认状态
        ↓
账本数据更新 → 刷新全局账本缓存
        ↓
点击"删除"按钮 → 确认删除
        ↓
如果是默认账本 → 提示"无法删除默认账本，删除前请先设置其他账本为默认账本"
        ↓
非默认账本 → 删除成功 → 账本数据更新 → 刷新全局账本缓存 → 列表刷新
```

## 三、接口定义

### 3.1 查询账本（分页）

**请求**

```
GET /accountBook/page
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 否 | 账本名称（模糊搜索） |
| pageNo | Integer | 否 | 页码（默认1） |
| pageSize | Integer | 否 | 每页条数（默认10） |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "totalCount": 2,
    "list": [
      {
        "id": 1,
        "userId": 1,
        "name": "日常账本",
        "image": "book.png",
        "isDefault": "YES",
        "createTime": "2026-03-01 10:00:00",
        "updateTime": "2026-03-01 10:00:00"
      },
      {
        "id": 2,
        "userId": 1,
        "name": "旅行账本",
        "image": "travel.png",
        "isDefault": "NO",
        "createTime": "2026-03-01 10:00:00",
        "updateTime": "2026-03-01 10:00:00"
      }
    ]
  }
}
```

### 3.2 创建账本

**请求**

```
POST /accountBook
```

**请求体**

```json
{
  "userId": 1,
  "name": "旅游账本",
  "image": "travel.png",
  "isDefault": "NO"
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 是 | 账本名称 |
| image | String | 否 | 账本图标 |
| isDefault | String | 否 | 是否默认账本（YES-是，NO-否） |

### 3.3 更新账本

**请求**

```
PUT /accountBook
```

**请求体**

```json
{
  "id": 1,
  "userId": 1,
  "name": "日常账本（修改）",
  "image": "daily.png",
  "isDefault": "YES"
}
```

### 3.4 删除账本

**请求**

```
DELETE /accountBook
```

**请求体**

```
[1, 2]
```

```
│  │ □ │ 账本图标  │ 账本名称             │ 操作     │         │
│  ├───┼───────────┼─────────────────────┼──────────┤         │
│  │ ☑ │ 📔        │ 日常账本 [默认]     │ [编辑][删除]│       │

│                                                              │

└─────────────────────────────────────────────────────────────┘
```

**页面功能说明：**

- **查询条件区域**：
  - 账本名称输入框：支持按账本名称模糊搜索
  - 查询按钮：执行搜索过滤
  - 重置按钮：清空搜索条件并显示全部

- **操作按钮**：
  - 新增账本：打开新增账本弹窗
  - 批量删除：删除选中的账本（需先勾选至少一条记录），按钮右侧显示已选中的数量，如"批量删除 (2)"

- **表格**：
  - 复选框列：支持多选
  - 账本图标：显示账本图标
  - 账本名称：显示账本名称，默认账本显示"默认"标签
  - 操作：编辑、删除按钮

- **分页**：
  - 显示总条数
  - 支持每页显示条数选择（10/20/50/100）
  - 支持页码跳转

### 5.2 新增/编辑弹窗

```
┌─────────────────────────────────────────────────────────────┐
│  新增账本                                         ✕          │
├─────────────────────────────────────────────────────────────┤
│  账本名称:  [________________________________]              │
│            (最多20个字符)                                     │
│                                                              │
│  账本图标:  [____________________________▼]                 │
│            (选择内置图标)                                    │
│                                                              │
│  默认账本:  [开关]                                           │
├─────────────────────────────────────────────────────────────┤
│                                             [取消] [保存]   │
└─────────────────────────────────────────────────────────────┘
```

> **图标方案推荐**：采用内置图标库方式，提供10-20个常用账本图标供用户选择。
> 优点：
> - 统一风格，美观协调
> - 无需上传，简便快捷
> - 无需处理图片存储和加载问题
> - 避免用户上传非图片文件或过大图片的问题
>
> 常见内置图标分类：
> - 日常/工作：📔、📒、📓
> - 旅行：✈️、🌍、🎒
> - 餐饮：🍜、🍕、☕
> - 购物：🛒、💳
> - 医疗：🏥
> - 教育：📚
> - 其他：💰、📊

## 八、数据缓存管理

账本数据用于收支记录等页面的账本选择功能，因此在账本发生新增、修改、删除操作后，需要刷新全局账本缓存。

**缓存刷新时机：**
- 新增账本成功后
- 修改账本成功后
- 删除账本成功后

**实现方式：**
调用 `getAccountBooks()` API 获取最新账本数据，更新到 `billStore.accountBooks`。
