# 支出限额设置模块 PRD

## 一、功能描述

### 1.1 功能概述

支出限额设置模块允许用户设置月度或年度支出预算，当实际支出接近或超过限额时，系统给出相应提示，帮助用户合理控制支出。

### 1.2 功能需求

- 查看当前支出限额设置
- 设置/修改月度支出限额
- 设置/修改年度支出限额
- 查看本月已使用额度
- 支出进度可视化展示

---

## 二、用户流程

```
用户进入支出限额设置页面
        ↓
查看当前限额设置（本月/本年）
        ↓
点击"编辑"或"设置"按钮
        ↓
输入新的限额金额
        ↓
保存设置
        ↓
返回成功提示，刷新页面
```

---

## 三、接口定义

### 3.1 获取用户配置

**请求**

```
GET /userConfig
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| type | String | 否 | 配置类型：MONTHLY-月度，YEARLY-年度 |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "type": "MONTHLY",
      "configKey": "expense_limit",
      "configValue": "10000",
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    }
  ]
}
```

### 3.2 设置支出限额

**请求**

```
POST /userConfig/additionalExpenseLimit
```

**请求体**

```json
{
  "userId": 1,
  "type": "MONTHLY",
  "expenseLimit": "10000"
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| type | String | 是 | 限额类型：MONTHLY-月度，YEARLY-年度 |
| expenseLimit | String | 是 | 限额金额 |

---

## 四、数据结构

### 4.1 用户配置 (UserConfig)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键ID |
| userId | Long | 用户ID |
| type | String | 配置类型：MONTHLY/YEARLY |
| configKey | String | 配置键 |
| configValue | String | 配置值 |

### 4.2 支出限额展示

| 字段 | 类型 | 说明 |
|------|------|------|
| monthlyLimit | BigDecimal | 月度限额 |
| yearlyLimit | BigDecimal | 年度限额 |
| monthlyExpense | BigDecimal | 本月已支出 |
| yearlyExpense | BigDecimal | 本年已支出 |
| monthlyProgress | Number | 月度进度百分比 |
| yearlyProgress | Number | 年度进度百分比 |
