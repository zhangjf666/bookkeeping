# 一般设置模块 PRD

## 一、功能描述

### 1.1 功能概述

一般设置模块用于管理用户的通用配置，包括常规配置和支出限额配置。用户可以设置新增收支记录时的默认行为，以及支出限额的金额和显示模式。

### 1.2 功能需求

- 查看用户配置列表
- 设置新增收支记录时是否默认选中信用卡
- 设置默认每年支出限额
- 设置默认每月支出限额
- 设置首页支出限额显示模式
- 修改配置后刷新全局缓存

---

## 二、用户流程

```
用户进入一般设置页面
        ↓
查看当前配置列表（按分组展示）
        ↓
修改常规配置（信用卡默认选中）
        ↓
自动保存 → 刷新缓存
        ↓
修改限额配置（年度/月度限额、显示模式）
        ↓
失去焦点或切换选项时自动保存 → 刷新缓存
```

## 三、接口定义

### 3.1 获取用户配置

**请求**

```
GET /userConfig
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 否 | 配置项名称（查询具体条目使用） |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "name": "is_credit_card",
      "value": "1",
      "description": "新增收支记录时是否默认选中信用卡",
      "enable": "YES"
    }
  ]
}
```

### 3.2 编辑用户配置

**请求**

```
PUT /userConfig
```

**请求体**

```json
{
  "id": 1,
  "userId": 1,
  "name": "is_credit_card",
  "value": "1",
  "description": "新增收支记录时是否默认选中信用卡",
  "enable": "YES"
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 配置ID |
| userId | Long | 是 | 用户ID |
| name | String | 是 | 配置项名称 |
| value | String | 是 | 配置项值 |
| description | String | 否 | 配置项描述 |
| enable | String | 是 | 是否启用（YES-是，NO-否） |

## 六、数据缓存管理

用户配置用于首页支出限额显示等功能，因此在配置发生修改后，需要刷新全局配置缓存。

**缓存刷新时机：**
- 修改任一配置项成功后

**实现方式：**
调用配置更新 API 后，更新 `userStore.userConfig` 或相关缓存，供其他页面使用。
