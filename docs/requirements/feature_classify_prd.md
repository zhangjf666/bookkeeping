# 分类设置模块 PRD

## 一、功能描述

### 1.1 功能概述

分类设置模块用于管理收支分类，方便对记账记录进行分类管理。

### 1.2 功能需求

- 查看分类列表（树形结构）
- 按分类类型筛选（支出/收入）
- 按分类名称搜索
- 新增分类（主分类/子分类）
- 编辑分类（不可修改类型）
- 删除分类（单条删除）
- 系统预置分类图标（共109个）供选择

---

## 二、用户流程

```
用户进入分类设置页面
        ↓
查看分类树（默认显示支出类型）
        ↓
点击类型切换（支出/收入）→ 切换显示对应类型的分类树
        ↓
(可选) 输入分类名称进行搜索 → 树自动过滤显示匹配的分类
        ↓
点击树节点 → 右侧显示编辑表单
        ↓
修改分类内容 → 保存
        ↓
分类数据更新 → 刷新全局分类缓存
        ↓
点击"新增"按钮 → 右侧显示新增表单（类型自动为当前树的类型）
        ↓
输入分类名称、选择图标、选择上级分类 → 保存
        ↓
分类数据更新 → 刷新全局分类缓存
        ↓
点击删除按钮 → 确认删除
        ↓
分类数据更新 → 刷新全局分类缓存 → 树刷新
```

## 三、接口定义

### 3.1 查询分类（分页）

**请求**

```
GET /classify/page
```

**请求参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 否 | 分类名称（模糊搜索） |
| type | String | 否 | 分类类型（EXPENSE-支出，INCOME-收入） |
| pageNo | Integer | 否 | 页码（默认1） |
| pageSize | Integer | 否 | 每页条数（默认10） |

**响应**

```json
{
  "code": 0,
  "msg": "ok",
  "data": [
    {
      "id": 1,
      "userId": 1,
      "name": "餐饮",
      "pid": -1,
      "image": "food",
      "sort": 1,
      "type": "EXPENSE",
      "enable": "YES",
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    },
    {
      "id": 2,
      "userId": 1,
      "name": "早餐",
      "pid": 1,
      "image": "breakfast",
      "sort": 1,
      "type": "EXPENSE",
      "enable": "YES",
      "createTime": "2026-03-01 10:00:00",
      "updateTime": "2026-03-01 10:00:00"
    }
  ]
}
```

### 3.2 创建分类

**请求**

```
POST /classify
```

**请求体**

```json
{
  "userId": 1,
  "name": "午餐",
  "pid": 1,
  "image": "lunch",
  "sort": 2,
  "type": "EXPENSE",
  "enable": "YES"
}
```

**字段说明**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| userId | Long | 是 | 用户ID |
| name | String | 是 | 分类名称 |
| pid | Integer | 是 | 父分类ID（-1表示主分类） |
| image | String | 是 | 分类图标（从系统图标库选择，如"food"、"lunch"） |
| sort | Integer | 否 | 排序号 |
| type | String | 是 | 分类类型（EXPENSE-支出，INCOME-收入） |
| enable | String | 否 | 是否启用（YES-启用，NO-禁用，默认YES） |

### 3.3 更新分类

**请求**

```
PUT /classify
```

**请求体**

```json
{
  "id": 2,
  "userId": 1,
  "name": "午餐（修改）",
  "pid": 1,
  "image": "lunch",
  "sort": 2,
  "type": "EXPENSE",
  "enable": "YES"
}
```

### 3.4 删除分类

**请求**

```
DELETE /classify
```

**请求体**

```
[1, 2]
```

## 四、数据结构

### 4.1 分类 (Classify)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键ID |
| userId | Long | 用户ID |
| name | String | 分类名称 |
| pid | Integer | 父分类ID（-1表示主分类） |
| image | String | 分类图标（系统图标库中的图标名称，如"food"、"lunch"） |
| sort | Integer | 排序号 |
| type | String | 分类类型（EXPENSE-支出，INCOME-收入） |
| enable | String | 是否启用（YES-启用，NO-禁用） |
| children | Classify[] | 子分类列表 |
| createTime | LocalDateTime | 创建时间 |
| updateTime | LocalDateTime | 更新时间 |

**页面功能说明：**

- **类型切换区域**：
  - 支出/收入单选按钮，切换显示对应类型的分类树
  - 搜索框根据当前类型进行过滤

- **搜索区域**：
  - 输入框带搜索图标
  - 输入分类名称后，树自动过滤显示匹配的分类（包括父节点）

- **左侧分类树**：
  - 显示分类树形结构，支持展开/折叠
  - 树节点显示图标和名称
  - 悬停时显示编辑和删除按钮
  - 点击节点选中并显示编辑表单

- **操作按钮**：
  - 新增分类：点击后右侧显示新增表单

- **右侧编辑区域**：
  - 点击树节点或新增按钮时显示编辑/新增表单
  - 显示当前分类类型（编辑时不可修改）
  - 新增时自动使用当前树的类型
  - 支持每页显示条数选择（10/20/50/100）
  - 支持页码跳转

### 5.2 编辑/新增表单

```
┌─────────────────────────────────────────────┐
│  编辑分类                                    │
├─────────────────────────────────────────────┤
│  分类类型:  [支出]                           │
│                                            │
│  上级分类:  [──────▼──────]                 │
│            (为空则为顶级分类，仅可选择主分类) │
│                                            │
│  分类名称:  [____________________]          │
│                                            │
│  分类图标:  [🍜] 点击选择图标               │
│                                            │
│  排序号:    [___]                           │
│                                            │
│  是否启用:  [☑] 启用                         │
│                                            │
├─────────────────────────────────────────────┤
│                              [取消] [保存]  │
└─────────────────────────────────────────────┘
```

**表单功能说明：**

- **分类类型**：
  - 编辑时：显示当前分类类型（不可修改）
  - 新增时：自动使用当前树的类型（支出/收入），不可修改

- **上级分类**：
  - 下拉框只显示当前类型的主分类（pid=-1的分类）
  - 选择"- 顶级分类（无上级）"表示创建主分类

- **分类图标**：
  - 显示当前选中的图标（正方形框）
  - 点击弹出图标选择器
  - 系统预置109个分类图标，每个唯一

## 八、数据缓存管理

分类数据用于收支记录等页面的分类选择功能，因此在分类发生新增、修改、删除操作后，需要刷新全局分类缓存。

**缓存刷新时机：**
- 新增分类成功后
- 修改分类成功后
- 删除分类成功后

**实现方式：**
调用 `getClassifyList(userId, type)` API 获取最新分类数据，更新到 `billStore.classifyList` 和 `billStore.classifyTree`。
